## Default Permission

Module state, public Catalog reads, URL subscription management, service control, policy groups, mode and bounded events, without shell, files or arbitrary HTTP access

#### This default permission set includes the following:

- `allow-read`
- `allow-subscription-read`
- `allow-subscription-action`
- `allow-subscription-write`
- `allow-management`
- `allow-service-action`
- `allow-policy-select`
- `allow-change-mode`
- `allow-policy-delay`
- `allow-cancel`
- `allow-open-events`
- `allow-next-event`
- `allow-close-events`
- `allow-visibility`
- `allow-set-appearance`
- `allow-pick-document`
- `allow-take-import`
- `allow-register-listener`
- `allow-remove-listener`
