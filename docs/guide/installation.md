# 安装与升级

## 安装前准备

- Android 12 或更高版本的 `arm64-v8a` 设备
- Magisk、KernelSU 或 APatch，以及可用的 Root 权限
- 支持 BPF、TC classifier、透明 socket 与 socket lookup 的内核
- local 模式还需要 veth 和策略路由能力

NetProxy 不提供 TPROXY 或 REDIRECT 回退。内核能力不足时，透明代理入站无法启动。

## 安装包

Release 与 CI 统一提供 `NetProxy_<版本>_<构建号>.zip`，包含模块和当前源码构建的 Android 管理器 APK。模块自更新也下载此包，安装管理器为可选步骤。

## 刷入模块

1. 从 [GitHub Releases](https://github.com/Fanju6/NetProxy-Magisk/releases) 下载模块包。
2. 在 Root 管理器中选择并安装。
3. 升级时选择安装方式：
   - **保留现有数据**：保留节点、订阅、模块日志及整个用户配置目录，包括模块设置、eBPF 设置、主配置、本地规则、自定义文件与核心持久状态。内置远程规则随安装包更新。
   - **仅保留节点与订阅**：保留 Catalog 与模块日志，配置、本地规则及核心持久状态恢复默认。用于保留节点但重新配置模块。
   - **全新安装**：不保留现有节点、订阅、配置或模块日志，使用安装包默认内容。
4. 音量键加循环选择，音量键减确认。未操作时，10 秒后默认保留现有数据；开始选择后，20 秒内未确认会取消安装。全新安装需要再次按音量键减确认，10 秒未确认会取消。
5. 选择是否安装管理器：音量键加安装或更新，音量键减跳过，10 秒未操作默认安装。无论是否已安装管理器，都会执行你的选择；覆盖更新使用固定签名并保留应用数据。

管理器安装失败会显示系统返回的原因，模块安装继续。安装器不会卸载原应用、清除数据或强制降级；选择跳过则不改变现有管理器。

::: warning 安装期间不要修改数据
安装完成前，请勿编辑模块配置、节点或订阅。保留模式要求当前配置文件与 Catalog 完整；缺少文件或存在未完成的写入时会中止安装，不会自动改为全新安装。请先备份并检查数据，或主动选择其他安装方式。
:::

在已开机环境中，安装器结束并写入待更新标记后，模块会在后台重新复制最新数据并应用更新，不要求立即重启。安装结束提示的短暂等待期间不要重启；热切换未完成时，模块保留暂存目录，由 Root 管理器在下次开机应用。Recovery 安装需要重启。

## 第一次启动

模块默认不会自动启动服务。安装后请：

1. 安装并打开 Android 管理器。
2. 导入本地节点或添加订阅。
3. 在节点页选择分组与自动/手动节点。
4. 返回仪表盘启动服务。
5. 确认状态为“运行中”后，再按需要开启自动启动。

下一步见[快速开始](/guide/quick-start)。

## 升级注意事项

- 不要从旧安装包手工复制二进制、运行时文件或临时状态目录。
- 运行时配置会根据持久设置重新生成，不需要备份。
- 内置远程规则随模块更新；用户本地规则和 Catalog 数据属于持久数据。
- 更新前正在运行的服务会在热切换后重新启动；原先停止的服务不会自动开启。安装失败会尝试恢复安装前的 Worker 与服务。
- 大版本历史背景见[架构迁移记录](/guide/compare-v7-v8)与[历史升级指南](/guide/upgrade-v7)，不要把历史路径当作当前操作说明。
