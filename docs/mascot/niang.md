# 奶屁娘

通路工坊的主人，成年龙系拟人角色。她有冰薄荷色长卷发、钴蓝蝴蝶结和深炭蓝裙装；讲究、有点傲娇，嘴上爱吐槽，遇到事情会先伸手帮忙。

## 形象识别

- 冰薄荷色长卷发，两侧带小辫。
- 大钴蓝蝴蝶结固定在角色自身右侧的后脑；正面通常出现在画面左侧。
- 两只小象牙角，刘海上是浅色 N 形标记。
- 青绿眼睛与深色上睫毛。
- 深炭蓝长袖裙装，浅色领口与袖口褶边，胸前薄荷蝴蝶结。
- 薄荷色龙尾与钴蓝折线尾鳍。
- 鞋袜采用五视图中的浅色褶边短袜与深色便鞋。

长发、蓝头饰和深色裙装是主要识别点。奶屁娘采用清晰线稿的插画风格，与像素风的奶屁龙形成搭配。

## 比例与色板

标准立绘采用成年 Q 版表现，头高约占全身三分之一；表情包可使用更夸张的头身比例。

| 用途 | 基准色 |
| --- | --- |
| 头发亮部 | `#D9F2EE` |
| 头发阴影 | `#9FCAD2` |
| 眼睛 | `#278F9F` |
| 头部蝴蝶结与尾鳍 | `#246FE2` |
| 连衣裙 | `#303442` |
| 角与领袖浅色部位 | `#FFF3D7` |
| 胸前蝴蝶结与尾巴 | `#91DACD` |
| 描边 | `#15212B` |

插画使用柔和阴影与高光，色板用于统一整体色相。

## 多视图

正面呈现双角、N 标记与胸饰；侧面呈现头饰的位置、头发体积和尾巴连接；背面突出长发、小辫与头饰。多视图保持相同的尺度、服装和年龄，故事动作可加入工具或热饮。

## 常用语气

“日志呢？”、“交给我”、“优雅收工”、“才不是担心你”。她可以俏皮、傲娇，也会在关键时刻照顾同伴；“本小姐”是她偶尔会使用的自称。
