# 角色创作规范

这页用于延展奶屁龙与奶屁娘的动作、表情和多视图。制作前先读[角色关系](./index)、[奶屁龙规格](./dragon)和[奶屁娘规格](./niang)，再下载标准图。

## 创作资源

| 内容 | 事实源 |
| --- | --- |
| 角色身份、关系与不可变特征 | 本组文档 |

以上路径均相对仓库的 `docs/`；下载入口见各角色页和[表情包页](./stickers)。

## 奶屁龙制作

1. 先对照参考图和 SVG 母版，保持头身比例、角、五官位置和尾巴轮廓。
2. WebUI 状态动作以 `base.svg` 为固定底图，另做两张透明 SVG 叠层；不得移动基础龙的身体、爪子或尾巴。
3. 原图未提供的角度参考正、侧、背视图补全结构。
4. 表情修改五官与小范围姿态。新增道具属于独立 `props` 图层，不覆盖主要识别点。
5. 保持透明背景、平涂色板与像素阶梯边界。
6. 与基准图并排检查，再检查目标小尺寸。两帧必须都能独立叠在基础龙上，不能依靠移动肢体制造动作。

交给代码型 AI 的提示词：

```text
为 NetProxy 的奶屁龙制作 [动作或表情]。
先阅读 /mascot/dragon 与 /mascot/production，并以 reference.png 和 base.svg 为依据。
保留原图轮廓、头身比例、象牙双角、额头阶梯 N、方眼、浅色腹部、蓝色背鳍和折线尾鳍。
输出纯 SVG 路径与可编辑图层，不嵌入 PNG、Base64 或外部图片。
仅改变表达该动作需要的部位，保持透明背景、固定色板和像素边界。
附基准对照与小尺寸预览；新角度注明为补全设计。
```

### 重建与检查

```sh
cd docs
node scripts/build-mascots.mjs
node scripts/build-mascots.mjs --check
npm run check
npm run build
```

生成代码从纯路径母版派生表情，不需要原始位图解码库。改母版后重新导出奶屁龙 PNG，并同步更新预览。

## 奶屁娘制作

使用生图模型时，将已有形象与五视图一并作为参考图片输入。每次生成一个明确动作，方便核对五官、服装和文字。

可复用提示词：

```text
用途：NetProxy 原创角色奶屁娘的 [立绘／多视图／表情包]。
参考图：reference.png 是身份参考，turnaround.png 是服装与结构参考。
成年 Q 版龙系少女：冰薄荷长卷发及侧辫、角色右后侧大蓝蝴蝶结、
象牙双角、浅色 N 刘海标记、青绿眼睛、深炭蓝长袖裙装、浅色领袖褶边、
胸前薄荷蝴蝶结、薄荷龙尾及蓝色折线尾鳍。
动作：[具体姿势]；表情：[具体情绪]；道具：[必要时填写]。
保持参考图的清晰插画线稿、身份与服装，透明背景，不裁掉头饰和尾巴。
多视图保持尺度、服装和不对称头饰位置；背面不出现五官或胸饰。
表情包文字必须是 “[准确文字]”，粗体清晰，不遮脸。
禁止短发替换、猫耳、翅膀、换色、另一个角色、联名标记与水印。
```

逐张检查头饰所在侧、双角数量、刘海 N、尾鳍和胸前蝴蝶结，再将通过检查的素材加入设定。

## 表情包规格

- 两位各 16 张，总计 32 张；每张独立文件。
- 标准发布文件为透明 PNG，画布 512×512，单张不超过 512 KiB。
- 人物与文字都在画布内；文字通常 2～7 字，边缘保留空间。
- 奶屁龙保留像素轮廓；奶屁娘采用深描边与浅色外轮廓。
- 中文逐字核对；必要时可在生成后单独排文字。
- SVG 是奶屁龙的编辑源，不作为 Telegram 静态贴纸直接上传；PNG 是导出产物。
- 文件命名采用 `01-received.png` 等编号和动作名，角色通过上级 `dragon/` 或 `niang/` 区分。

## 验收清单

- [ ] 奶屁龙和奶屁娘的名称、身份与形象正确。
- [ ] 奶屁龙保留像素风与纯 SVG 路径；奶屁娘保持长发形象。
- [ ] 多视图的双角、头饰、服装和尾巴一致。
- [ ] WebUI 动作使用两张透明状态层，基础龙不移动，减少动画设置有效。
- [ ] 文字、透明背景、512×512 尺寸和 512 KiB 上限检查通过。
- [ ] 小尺寸、浅色和深色背景均可识别。
- [ ] 新增素材入库、清单同步、链接有效。
