# NetProxy 隐私政策

生效日期：2026 年 1 月 3 日<br>
最近更新：2026 年 10 月 8 日

NetProxy 是开源软件。本政策说明模块、Android 管理器和本文档站在正常使用中如何处理数据。

## 设备本地数据

NetProxy 的模块设置、节点、订阅、更新历史、运行状态和日志默认保存在你的设备上。Android 管理器通过设备上的 Root 命令与模块通信，不会把这些内容同步到开发者服务器。

节点凭据、订阅 URL、自定义 Header 和应用名单可能包含敏感信息。请保护设备 Root 权限，并谨慎向其他应用或人员开放模块目录。

## 订阅与第三方服务

订阅地址由你自行添加。更新订阅时，设备会直接访问对应订阅服务，并按你的设置发送 User-Agent、自定义 Header、HWID 或其他必要请求信息。该服务如何处理请求由其运营方的隐私政策决定，NetProxy 开发者无法控制。

Root 管理器、代理服务、DNS 服务、GitHub 及你选择的分享应用也可能按各自政策处理数据。

## 设备与活跃统计

正式模块默认通过 Go Worker 向 PostHog US Cloud 发送设备活跃统计，没有单独的关闭开关；Android 管理器和 WebUI 不接入统计 SDK。

统计只有两类事件：每日模块活跃、实际 sing-box 启动尝试的成功或失败。上报内容限于派生的设备 ID、模块版本与版本代码、事件时间，以及启动结果、耗时和固定失败阶段。为分析兼容性分布，还会附带有限类别的 Root 方案、Android API、内核主次版本和厂商归类；例如内核只保留 `6.6`，厂商只归入预定义类别或 `other`。Worker 以 Root 读取系统用户 0 的 Android ID，并使用固定 NetProxy 命名空间进行 SHA-256 哈希；原始 Android ID 不落盘、不上传。该摘要用于跨重装关联同一设备，属于假名化标识，并不等于完全匿名。不读取或上报机型、设备代号、完整内核字符串、Build Fingerprint、IMEI、序列号、MAC、节点、订阅 URL、Header、SSID、应用名单、访问目标、配置或日志。

只要系统 Android ID 未变化，升级、全新安装、仅保留节点与订阅或卸载重装模块都使用相同设备 ID；多用户和应用分身也统一按系统用户 0 计数。恢复出厂设置、刷机清除系统数据或人为修改 Android ID 可能产生新的设备 ID。设备 ID 不对应账号或自然人，一人多设备、多人共用设备和无法联网等情况会影响统计，因此日活、月活和累计设备数不是精确人数，也不保证等于物理设备总数。读取失败时暂不上报，不生成随机替代 ID。

设备 ID 由 Worker 在内存中派生；每日去重状态与待发送事件保存在 Root 可读的 `config/telemetry/state.json`，本地队列不保存设备 ID，也不会加入诊断包。离线队列最多保留 64 条、64 KiB 和 7 天；上传失败会退避重试，不阻止模块操作。上述期限仅适用于设备队列，不是云端删除期限。

事件经 HTTPS 发送至 `us.i.posthog.com`，使用美国区域的 PostHog 托管服务。请求接收方可以看到网络请求的 IP 地址；NetProxy 不主动上报 IP，并禁用事件的 GeoIP 补充与用户档案处理。云端数据按项目保留设置和 [PostHog 隐私政策](https://posthog.com/privacy) 处理。

## 日志与诊断包

日志保存在设备本地。诊断包只有在你主动导出并通过所选应用分享后才会离开设备。

导出流程会脱敏已知的订阅地址、凭据、UUID、Header 和设备标识，并排除 Catalog 节点数据；但自动脱敏无法保证识别所有自定义内容。分享前请确认文件内容和接收方。

开发者只会在你主动提交反馈时收到诊断信息，不会在后台自动收集模块日志。

## 文档站与广告

本文档站加载 Google AdSense。Google 可能使用 Cookie、本地存储、IP 地址、浏览器信息或广告标识来投放、衡量和防止广告欺诈。你可以通过浏览器设置或 Google 的广告隐私设置管理相关选项。

文档站托管服务也可能记录访问所必需的服务器日志。相关处理由托管服务提供方负责。

设备统计页嵌入 PostHog 的公开仪表盘，展示汇总数据，不公开设备标识或单条事件。打开该页时，浏览器会连接 `us.posthog.com` 加载仪表盘，PostHog 可接收到 IP 地址和浏览器请求信息；相关处理适用 [PostHog 隐私政策](https://posthog.com/privacy)。

## 数据共享

开发者不会出售你的节点、订阅或模块配置。设备活跃统计由 PostHog 托管；反馈内容仅在你主动提交或法律要求时处理。为协助排查而转交给项目协作者的内容会限制在解决问题所需范围内。

## 儿童隐私

NetProxy 不面向 13 岁以下儿童，也不会故意收集儿童个人信息。如果你认为儿童向开发者提交了个人信息，请联系删除。

## 政策变更

本政策会随实际数据处理方式更新。新版本将在此页面公布，并标注最近更新日期。
